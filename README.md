# Traffic Statistic

Мод для **Cities: Skylines II**: статистика общественного транспорта в отдельном окне. Открывается иконкой
с графиком на верхней левой панели игры. Интерфейс на русском или английском, по языку игры.

**Текущая версия: 0.6.3.**

## Возможности

- **Вкладки видов транспорта:** автобус, трамвай, метро, поезд, корабль, паром, самолёт, вертолёт. Серые,
  если таких линий в городе нет.
- **Список линий** с заполненностью прямо сейчас (зелёный / жёлтый > 80% / красный > 100%), сортировкой
  внутри вида (по номеру, сначала заполненные, сначала пустые, по имени), кнопкой открытия линии в игре
  и кнопкой удаления линии (с подтверждением; статистика линии тоже стирается).
- **График** по часам (последние 7 игровых суток) и по суткам (всё время; среднее, пик или оба).
  Величины: едут, заполненность %, ждут на остановках, машин на линии, вошло. Каждая линия отдельно,
  сумма по видам или общая сумма.
- **Таблица** линий с сортировкой и подсказками к столбцам: едут, заполненность, ждут, машин, вошло за
  сутки, пик за сутки, доля пришедших с пересадки.
- **Остановки:** схема линии (ждут, вошло, вышло, загрузка каждого перегона) и таблица всех остановок
  города. Щелчок переносит камеру.
- **Пересадки:** с каких линий и на какие пересаживаются, пересадочные узлы и цепочки поездок
  («автобус 5 → поезд 1 → автобус 7»).
- **Куда едут:** зачем едут пассажиры (работа, дом, магазин, учёба, отдых…) и в какие здания приезжают,
  с фильтром по типу здания и подсветкой этих зданий на карте.

История хранится в `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\TrafficStatistic\<город>.txt`,
а не в сохранении, поэтому отключение мода сохранения не ломает.

## Сборка

Нужен .NET 8 SDK. Проект собирается против библиотек самой игры (`Cities2_Data\Managed`), без NuGet.

Папка игры по умолчанию — Steam (`C:\Program Files (x86)\Steam\steamapps\common\Cities Skylines II`).
Если игра в другом месте, создай рядом с проектом файл `GameDir.props` (он не попадает в git):

```xml
<Project>
  <PropertyGroup>
    <GameDir>D:\Games\Cities Skylines II</GameDir>
  </PropertyGroup>
</Project>
```

Собрать и установить в папку локальных модов игры
(`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\TrafficStatistic`):

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Интерфейс — один написанный вручную модуль `ui/TrafficStatistic.mjs` (React из игры, без сборщика).
Логи мода: `...\Cities Skylines II\Logs\TrafficStatistic.log`.
